# Day 16 — Power BI Fundamentals

## Objective
Practice importing data, preparing it in Power Query, and building an interactive report in Power BI Desktop.

## Learning Objectives
- Set up Power BI Desktop and understand its interface.
- Connect to a CSV data source.
- Transform and prepare data using Power Query.
- Create basic data visualizations and interactive report elements.
- Understand the foundations of data modeling and reporting.

## Data Source
- `sales_data.csv`
- Sample sales data containing 8 orders across 4 regions and 3 categories.
- Fields: OrderID, OrderDate, Region, Category, Sales, and Profit.

## Tasks Performed
- Imported the CSV file into Power BI Desktop.
- Checked and updated column data types in Power Query.
- Created a Sales by Category column chart.
- Added a Total Sales KPI card.
- Added a Region slicer.
- Created a sales detail table.
- Created a Sales by Region chart.

## Concepts Practiced
- Data import and Power Query
- Column data types
- Charts and KPI cards
- Slicers and interactive filtering
- Basic report layout

## Deliverables
- `sales_data.csv` — practice dataset
- `Day16_Sales_Dashboard.pbix` — Power BI report, once saved

## Notes
This project uses a small sample dataset for learning purposes. It does not represent real business data.

## Conclusion
Practiced the basic Power BI workflow from importing and preparing data to creating visualizations and interactive report elements.
