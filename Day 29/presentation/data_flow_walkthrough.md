# Data Flow Walkthrough

```text
CSV source datasets
       |
       v
Extraction / file loading
       |
       v
Structural and data-quality checks
       |
       v
Cleaning and transformation
       |
       v
SQL analysis / Python analytics
       |
       v
Summary outputs and analytical datasets
       |
       v
Power BI data model and report
       |
       v
Business interpretation and decisions
```

## Demo sequence
1. Show the source data folder and explain each dataset.
2. Open the actual Python scripts/notebook and SQL queries.
3. Explain one representative transformation or join.
4. Show validation report outputs from Day 29.
5. Open the Power BI PBIX and explain the report pages and filters.
6. Explain one insight and how a business user could act on it.
