# Day 4 - NumPy Fundamentals and Performance

## Overview
This project demonstrates NumPy concepts for numerical computing and data engineering.

## Learning Objectives
- Create and manipulate NumPy arrays.
- Perform indexing, slicing, reshaping, and broadcasting.
- Apply mathematical and statistical operations.
- Filter data using Boolean masks and np.where().
- Compare Python loops with NumPy vectorization.
- Analyze sales data using NumPy.

## Project Structure
- notebooks/numpy_operations.ipynb - Interactive NumPy notebook.
- scripts/01_array_fundamentals.py - Array creation and manipulation.
- scripts/02_array_operations.py - Arithmetic and statistical operations.
- scripts/03_boolean_filtering.py - Boolean filtering.
- scripts/04_vectorization_benchmark.py - Performance comparison.
- scripts/05_statistical_analysis.py - Sales data analysis.
- data/ - Input datasets.
- outputs/sales_analysis.csv - Generated sales analysis.

## How to Run
Install the dependencies:
python -m pip install -r requirements.txt

Run an example:
python scripts/01_array_fundamentals.py

Launch Jupyter:
python -m notebook

## Key NumPy Functions
array(), zeros(), ones(), arange(), linspace(), reshape(),
mean(), median(), std(), percentile(), unique(), and where().
