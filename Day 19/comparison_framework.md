# Comparison Framework

Use the same dimensions for both fields. Treat the prompts below as questions to investigate, not universal definitions.

| Dimension | Data Science: investigate | Decision Science: investigate |
|---|---|---|
| Primary objective | What insights or estimates are produced from data? | How are alternatives evaluated and choices supported? |
| Typical question | What happened, why, or what may happen? | What action should be taken given goals and constraints? |
| Inputs | Data, features, domain context | Objectives, alternatives, evidence, preferences, constraints |
| Methods | Statistics, data analysis, machine learning, visualization | Decision analysis, optimization, simulation, trade-off analysis |
| Outputs | Insights, forecasts, models, dashboards | Evaluated alternatives, recommendations, policies |
| Evaluation | Predictive accuracy, calibration, validity, usefulness | Objective attainment, feasibility, robustness, sensitivity |
| Applications | Forecasting, segmentation, anomaly detection | Resource allocation, scheduling, campaign planning |
| Limitations | Data quality, bias, uncertainty, model drift | Incomplete objectives, uncertain inputs, value judgments |
| Relationship | Can supply evidence and predictions | Can use evidence and predictions to compare actions |

## Synthesis prompts
- Which differences are emphasis rather than strict boundaries?
- What is missing when a prediction is not tied to a decision objective?
- How can decision analysis use predictive estimates?
- Which assumptions or value judgments affect a choice?
