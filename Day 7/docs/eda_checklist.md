
# Exploratory Data Analysis (EDA) Checklist

## 1. Understand the Dataset
- [ ] Identify the number of rows and columns.
- [ ] Review column names and data types.
- [ ] Inspect sample records.
- [ ] Identify numerical, categorical, datetime, and text columns.

## 2. Data Quality
- [ ] Check missing values.
- [ ] Check duplicate rows and duplicate identifiers.
- [ ] Validate data types.
- [ ] Check invalid or inconsistent values.
- [ ] Document cleaning decisions.

## 3. Statistical Analysis
- [ ] Calculate mean, median, minimum, and maximum.
- [ ] Calculate variance and standard deviation.
- [ ] Calculate quartiles and percentiles.
- [ ] Examine skewness and kurtosis.
- [ ] Review correlations between numerical variables.
- [ ] Apply statistical tests only when their assumptions and purpose are appropriate.

## 4. Visual Analysis
- [ ] Plot numerical distributions.
- [ ] Examine outliers using box plots or the IQR method.
- [ ] Compare categories using bar charts.
- [ ] Review correlation patterns.
- [ ] Analyze trends over time when dates are available.

## 5. Pattern Identification
- [ ] Identify top-performing categories.
- [ ] Compare customer spending.
- [ ] Review monthly sales trends.
- [ ] Investigate unusual observations.
- [ ] Avoid treating correlation as proof of causation.

## 6. Reporting
- [ ] Save statistical summaries.
- [ ] Save data-quality reports.
- [ ] Save visualizations.
- [ ] Document findings and limitations.
- [ ] Verify notebooks run from top to bottom.
- [ ] Ensure outputs and source files are organized.
