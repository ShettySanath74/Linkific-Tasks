# Day 17 — DAX and Advanced Power BI

## Objective
Practice DAX fundamentals, reusable measures, time-intelligence calculations, and advanced Power BI report features.

## Data Source
- `sales_data.csv` — sample sales data
- Fields: OrderID, OrderDate, Region, Category, Sales, Profit

## Work Completed
- Created a date table and connected it to the sales data.
- Created DAX measures for Total Sales, Total Profit, and Profit Margin.
- Practiced previous-month sales and year-to-date sales calculations.
- Created a running total and sales ranking measure.
- Created previous-year sales and year-over-year growth measures.
- Built a Region Details page and tested drill-through from the main report.
- Added a sales matrix comparing regions and categories.

## Concepts Practiced
- Measures and filter context
- CALCULATE, DATEADD, TOTALYTD, FILTER, ALL, and RANKX
- Time-intelligence calculations
- Date-table relationships
- Drill-through and report navigation

## Deliverables
- `Day17_DAX_Advanced_Dashboard.pbix` — Power BI report
- `sales_data.csv` — practice dataset
- `README.md` — project guide

## Notes
The sample data covers January–March 2026 only. Previous-year comparisons may return blank because no 2025 sales data is available. This is a practice dataset, not real business data.
